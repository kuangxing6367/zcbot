# 扩展清单

> **官方扩展大部分默认关闭**，但有少数例外**默认开启**：`echo`（连通性自检）、`help`（帮助菜单）、`scheduler`（定时任务调度）、`webui`（Web 管理后台）。
> 其余接入端与功能插件默认关闭，需显式启用：把对应块 `enabled` 改为 `true`，或 `python tools/scan_core_plugins.py --enable <名>`，然后重启。

## 官方内置扩展（core_plugins/）

| 扩展 | 作用 | 默认 |
| ---- | ---- | ---- |
| **echo** | 连通性自检：`/echo` 原样回显、`/ping` 健康检查（覆盖所有接入端） | ✅ 开 |
| **help** | 内置帮助菜单：`/help`（别名 `/帮助`、`/菜单`）列出全部已注册命令 | ✅ 开 |
| **scheduler** | 定时任务调度（APScheduler cron） | ✅ 开 |
| **webui** | Web 管理后台（端口/仪表盘/插件市场） | ✅ 开 |
| **onebot_adapter** | OneBot 11 反向 WS 接入端（协议端连入） | ❌ 关 |
| **rust_accel** | OneBot 的 **Rust 加速接入端**（启用前先停 `onebot_adapter`，详见 `core_plugins/rust_accel/README.md`） | ❌ 关 |
| **ws_client** | 正向 WS 接入端（主动连协议端） | ❌ 关 |
| **qq_official** | QQ 官方机器人接入（需 AppID/AppSecret） | ❌ 关 |
| **telegram** / **discord** | Telegram / Discord Bot 接入（需 Token） | ❌ 关 |
| **session** | 多轮会话：`ctx.wait_for()` / `ctx.create_session()` | ❌ 关 |
| **http_api** | 独立对外 HTTP API | ❌ 关 |
| **http_inject** | HTTP 事件注入端 | ❌ 关 |
| **image_renderer** | 通用图片渲染引擎（卡片/文字图，Rust 原生加速、缺失回退 PIL） | ❌ 关 |
| **html_assembler** | 单文件 HTML 装配引擎：占位符替换 + 图片 base64 内嵌 | ❌ 关 |
| **llm_load** | LLM 核心装载器：释放/自愈 `plugins/llm_core`（对话核心，提供模型总线 / 工具调用 / Agent 循环） | ❌ 关 |
| **aiwriter** | AI 智能体 CLI：`python main.py code` 或终端 `code` 打开全屏界面（可配置 OpenAI / 写插件），不依赖 llm_core | ❌ 关 |

## 随项目内置的用户扩展（plugins/）

> 以下插件位于 `plugins/` 目录，**默认全部加载**（除非在 `core_plugins.yaml` 或后台显式禁用）。
> `echo` / `help` 已作为官方自检/帮助入口移入 `core_plugins/`（见上表），不再列于此。

| 扩展 | 显示名 | 作用 |
| ---- | ------ | ---- |
| `Lolicon` | 随机动漫图 | Lolicon API 随机动漫插画，触发词被动下发 + /setu 主动命令 |
| `big_banana` | 绘图 | OpenAI/Gemini 兼容的图像生成，支持高级参数 |
| `context_aware` | 群聊场景感知 | 维护群聊对话流，推断谁在和谁说话，辅助 Bot 避免抢答 |
| `daily_pig` | 今日小猪 | 每人每日抽取专属小猪，当日固定、次日刷新，猪库可自定义 |
| `dzmm` | DZMM 聊天 | 对接 dzmm.ai 兼容 OpenAI 聊天接口，多角色/多密钥/上下文隔离/失败自动切换 |
| `emoji_like` | 智能贴表情 | 按概率调用 LLM 判断消息情感并贴对应表情，缺失 LLM 配置时随机降级 |

| `group_guardian` | 群管卫士 | 群管操作 + 违禁词 + 可选 LLM 智能审核，正则初筛与二次判定 |
| `human_service` | 人工客服 | 群内转人工：用户消息转发给管理员、管理员回复回传，状态持久化 |
| `humanlike` | 更像真人 | 随机忽略/已读不回/夜间睡觉不回，让 Bot 更像真人 |
| `life_scheduler` | 生活日程 | LLM 生成拟人化每日日程与穿搭，存储可查询，支持定时生成 |
| `link_parser` | 万能链接解析 | 按域名分发解析视频/图集/音频链接，解析器可插拔扩展 |
| `matrix_adapter` | Matrix桥接 | Matrix 协议桥接：把 Matrix 房间消息转发到 QQ 群（依赖 matrix-nio） |
| `mcon` | MCON 互通核心 | 《我的世界》服务器主动上报心跳(玩家/TPS/MSPT)与日志；北京时间动态轮换 Token |
| `meme_manager` | 表情管理器 | 按目录组织表情素材，支持随机发送、关键词匹配、群内收录与 Web 管理 |
| `memeify` | 表情包 | 识别 LLM 回复中的 [表情词] 或主动命令，调用 apihz.cn 发送表情包图片 |
| `message_stats` | 群发言统计 | 群发言计数与排行（总/今日/昨日/周/月/年），缓冲落库 + 定时推送 |
| `msg_stats` | 群发言统计 | 群发言计数与字数统计，缓冲批量落库，支持日榜/总榜/仪表盘 |
| `music` | 点歌 | 关键词搜歌并发送音乐卡片，搜索源可配置 |
| `novel` | 群协作小说 | 每群独立的长篇小说协作：世界观/人物/AI续写/大纲/导出 |
| `portrayal` | 人物画像 | 基于群聊历史发言统计 + 可选 LLM 生成群友性格画像，带当日缓存 |
| `qzone_ultra` | QQ空间发布 | 经本地 QZone 网关发布内容到 QQ 空间（守护进程架构，凭证不下放） |
| `reneban` | 黑名单管理 | 会话/全局用户禁用与解禁，支持时限与理由，pass>ban，过期自动清理 |
| `reread` | 复读姬 | 纯内存群聊复读：分类型阈值 + 概率 + 冷却 + 违禁词 |
| `shit_detector_plus` | 搬史专家 | 搜索 GitHub 项目并用 LLM 做史级评定，支持定时推送精选项目到群聊 |
| `steam_monitor` | Steam 状态监控 | 轮询 Steam 玩家游戏状态，变更时推送到绑定的群 |
| `video_sora` | 视频生成 | OpenAI Sora / 兼容视频生成接口，支持提交与轮询 |
| `web_analyzer` | 网页分析 | 抓取网页正文并可选 LLM 摘要，按 URL 缓存 |
| `what_to_eat` | 吃什么 | 智能识别「吃什么」问句，按概率推荐美食或复读，支持自定义食物库/频率限制/复读冷却 |
