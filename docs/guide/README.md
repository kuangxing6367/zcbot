# ZCBOT 开发文档

ZCBOT 是一个插件化的聊天机器人框架，核心极简，所有功能通过官方插件和用户插件按需加载。支持 OneBot（QQ）、WebUI、HTTP API、定时任务、权限系统等。

└──────────────────────┬──────────────────────────┘

## 特性

- **插件化架构**：核心极简，OneBot/WebUI/会话/调度/HTTP API 均为可选插件
- **全异步**：消息处理、API 调用、定时任务均不阻塞事件循环
- **内置多轮会话**：`ctx.wait_for()` / `ctx.create_session()` 开箱即用
- **Web 管理面板**：可视化管理插件、命令、用户、群组
- **双数据库**：SQLite 零配置 / MySQL 可选
- **热重载**：插件代码修改后无需重启
- **HTTP API**：外部程序通过 REST 接口与框架交互
- **权限系统**：LuckPerms 风格，节点 + 继承 + 上下文
