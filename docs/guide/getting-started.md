# 开始使用

安装完成、看到「框架启动完成」后，按本页三步走：**确认启动成功 → 选一条路线 → 第一次对话 / 打开后台**。

## 1. 启动

```bash
python main.py
# 也可指定配置：python main.py D:\config\zcbot.yaml
```

成功时大致长这样：

```
==================================================
ZCBOT 框架 启动中...
==================================================
官方插件 [onebot_adapter] 已加载
官方插件 [scheduler] 已加载
官方插件 [session] 已加载
官方插件 [webui] 已加载
已加载 8 个用户插件: ['echo', 'help', ...]
框架启动完成，等待事件...
```

出现最后一行 `框架启动完成，等待事件...` 即就绪。日志同时写在 `data/logs/zcbot.log`。

**没报错？** 直接往下。**报错了？** 看日志最后几行；依赖问题多半会在启动时自动补装后重试。

## 2. 选一条路线

| 你想干什么 | 走哪条 | 要接聊天平台吗 |
| ---------- | ------ | -------------- |
| 在 QQ / TG / Discord 收发消息、跑命令 | [对接 IM 平台](./connect-im.md) | 要 |
| 每天定时干活（日报、检查、推送） | 用 `scheduler` 定时任务 | 不要 |
| 外部系统 POST 事件进来触发逻辑 | 开 `http_inject` | 不要 |

**只想先试通？** 任选一条：

- **有聊天平台** → 按 [对接 IM](./connect-im.md) 连上后，发 `/echo 你好`
- **完全不接平台** → 在 `core_plugins.yaml` 关 `onebot_adapter`，开 `http_inject`，然后：

```bash
curl -X POST http://127.0.0.1:8901/hook \
     -H "Content-Type: application/json" \
     -d '{"user_id": 10001, "message": "/echo 来自 HTTP"}'
```

命令逻辑照常跑——**没有 IM 也能用**。

## 3. 第一次对话（已对接平台时）

对机器人发：

```
/echo 你好
```

它原样回 `你好` 就说明链路通了。再发 `/help`（或 `/帮助`、`/菜单`）看全部命令。

## 4. 打开 Web 管理后台

浏览器访问：`http://127.0.0.1:8080`（端口以 `core_plugins.yaml → webui` 为准）

| | |
| --- | --- |
| 用户名 | `admin` |
| 密码 | `admin123` |

登录后可以：开关/重载插件、管理命令与定时任务、管权限、看仪表盘和日志、在线改配置。

:::warning 首次登录必做
1. **立刻改默认密码**（设置 → 修改密码）。
2. 若要公网访问：`web.host` 保持 `127.0.0.1` + 反向代理；接入端设好 `access_token`；按需配 IP 白名单。
:::
