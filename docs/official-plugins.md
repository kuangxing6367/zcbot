# 官方插件使用手册

> 官方插件仓库：<https://github.com/kuangxing6367/zcbot_plugins>
>
> 使用方式：把 `config.yaml` 的 `plugin.dir` 指向官方插件仓库的 `plugins` 目录，然后在后台「插件市场」安装，或在「插件管理」页启用。部分插件会随框架一起分发。

```yaml
plugin:
  dir: ../zcbot_plugins/plugins
```

本文按插件功能分类，介绍每个官方插件的**调用方式**（群/私聊里发什么命令、触发什么效果），全部基于插件源码中实际注册的命令，可直接照抄使用。

## 一、AI 对话类

### `llm_chat` — 大模型聊天

接入 OpenAI 兼容接口，让机器人变成 AI 聊天机器人。支持上下文记忆、好感度、长期记忆、人格设定、API 池轮换。

| 命令 | 说明 | 权限 |
| ---- | ---- | ---- |
| `/chat 你想聊的内容` | 发起 / 继续对话 | 所有人 |
| `@机器人 内容` | 直接 @ 机器人聊天 | 所有人 |
| `/好感度` | 查看与机器人的好感度 | 所有人 |
| `/记忆` | 查看长期记忆 | 所有人 |
| `/人格`（`/persona` `/人设`） | 查看/切换人格设定 | 所有人 |
| `/会话` | 管理多轮会话 | 所有人 |
| `/函数列表` | 查看 AI 可调用函数 | 所有人 |
| `/对话统计` | 对话使用统计 | 所有人 |
| `/检测api` | 检测 API 池可用性 | 超管 |
| `/api池` | 管理 API 池 | 超管 |

**调用例子：**

```
# 群里
/chat 帮我写一首关于夏天的诗

# 直接 @ 机器人（无需 /chat）
@机器人 今天天气怎么样

# 切换人格
/人格 傲娇助手
```

配置：`base_url` / `api_key` / `model` 等在后台插件配置里填写。自带 WebUI 控制台（后台「插件 WebUI」→「LLM 对话」）。

### `minecraftconsole` — MC 服务器控制台

在群里管理 Minecraft 服务器：执行 RCON 命令、管理白名单、AuthMe 注册/改密/强制登录。

| 命令 | 说明 | 权限 |
| ---- | ---- | ---- |

**调用例子：**


配置：`rcon_host` / `rcon_port` / `rcon_password` / `db_*` 等。

## 七、安全防护类

### `message_guard` — 消息防护

消息前端守卫，静默拦截（无命令）。包含：

- **唤醒词**：只有包含唤醒词的消息才会继续处理（`wake_enable`）
- **群白名单**：只处理白名单群（`whitelist_enable`）
- **用户黑名单**：黑名单用户消息直接丢弃
- **限流**：同用户短时间内消息条数限制（`rate_count` / `rate_seconds`）
- **敏感词**：命中敏感词直接拦截（`sensitive_words`）

配置项（后台插件配置）：`wake_enable` / `wake_prefixes` / `whitelist_groups` / `blacklist_users` / `rate_enable` / `rate_count` / `rate_seconds` / `sensitive_enable` / `sensitive_words` / `exempt_admin`。

**使用方式**：无需命令，启用插件后按配置自动生效。

## 九、个性化前端 `custom_ui`

从 GitHub 拉取网页模板接管整个 Web 管理面板，并提供模板管理界面。

- 启用后，访问 `http://你的地址:8080/` 会被重定向到插件提供的模板网页
- 模板管理页：`http://你的地址:8080/custom_ui/manage`（模板列表 / 下载 / 安装 / 切换）
- 多模板并存，切换后刷新网页生效
- 刷新过快（5 秒内 2 次）会自动跳转到 `/reset` 恢复页，可一键恢复框架默认前端

**使用流程：**

1. 安装并启用 `custom_ui` 插件
2. 打开 `http://你的地址:8080/custom_ui/manage`
3. 在「可用的远程模板」里点「下载」
4. 在「已下载模板」里点「切换启用」
5. 刷新网页，模板生效

**恢复默认前端：** 后台模板管理页点「禁用插件，恢复框架默认前端」，或访问 `/reset`。

## 附录：常见问题

**Q: 命令没反应？**
A: ① 确认插件已启用（后台「插件管理」看状态）；② 确认命令格式正确（有的命令不带 `/`，如 `签到`、`禁言`）；③ 看日志确认权限是否满足。

**Q: 权限不足？**
A: 超管命令（`/ai`、`/重启`、`/插件拉黑`、文件管理类）需要超级管理员身份；qqadmin 的群管命令按群主/管理员/协管分级。

**Q: 怎么知道自己有哪些插件？**
A: 群里发 `/plugins`（runtime_status 插件）或 `/pluginlist`（llm_plugin_gen 插件）。
